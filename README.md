# latitudinal-airborne-constraints
R code used to perform the analyses and generate the plot and table output presented in Stephens et al., Improved latitudinal carbon budgets from global airborne surveys, Proc. Nat. Acad. Sci., https://doi.org/10.1073/pnas.2309333121, 2026.

See master script all_lac.r for instructions on how to download necessary data files and the sequence for running all other scripts.
